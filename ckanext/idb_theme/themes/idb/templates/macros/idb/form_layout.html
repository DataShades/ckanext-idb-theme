{# Components for multi-step, multi-section entity forms (create/edit pages). They only render markup. The `form-sections` JS module (javascript/modules/form-sections.js) adds the behaviour: completion counters, the progress bar, navigation, and enabling the "next" button. The module looks only at data attributes, so any entity form can use these components. Example: {%- call ui.util.call(ui.stepper) -%} {{ ui.stepper_step(_("Create Dataset"), 1, "active") }} {{ ui.stepper_step(_("Add data"), 2) }} {%- endcall %} {%- call ui.util.call(ui.form_section, title=_("Overview"), id="overview", total=3, open=true) -%} {%- call ui.util.call(ui.form_section_field, name="title", required=true) -%}...{%- endcall %} {%- endcall %} #} {#- Horizontal list of steps.
